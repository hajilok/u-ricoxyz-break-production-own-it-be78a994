# Break Production, Own It

Entry for the [make.fun Break Production, Own It](https://make.fun/r/41fw6r6c) competition (`u-ricoxyz-break-production-own-it-be78a994`).

## Usage

Requires Node.js 22.18+ (no external dependencies):

```bash
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Writes a deterministic single-line UTF-8 entry (`<= 200` characters) to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` for local testing).
